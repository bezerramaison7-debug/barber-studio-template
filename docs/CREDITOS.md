# Créditos das imagens

[Licença Unsplash](https://unsplash.com/license), que permite uso comercial gratuito sem exigir
atribuição. Elas são **apenas ilustrativas**: não mostram o estabelecimento, a equipe nem
trabalhos reais da marca fictícia Barber Studio.

Para um cliente real, substitua todas por fotos próprias do estabelecimento, com autorização
de uso de imagem das pessoas que aparecem.
